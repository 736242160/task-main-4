# ============ 兽药定义 ============
DRUG 阿莫西林 7
DRUG 恩诺沙星 14

# ============ 建群 ============
GROUP A 100
GROUP B 80

# ============ 用药流 ============
MED A 阿莫西林 2026-01-01        # A: 到期 2026-01-08
MED A 恩诺沙星 2026-01-05        # 重复用药叠加：A 有效到期取最晚 = 2026-01-19
MED B 阿莫西林 2026-01-10        # B: 到期 2026-01-17

# 休药期内出栏 -> 拦截并报告剩余天数
SLAUGHTER A 2026-01-10 20        # 剩 9 天，拦截

# ============ 转群继承样例 ============
# A 全部并入 C（C 不存在，自动建群），C 继承 A 的最晚到期日 2026-01-19
TRANSFER A C 100
# 混群：B 也并入 C，C 取所有来源最长剩余期（仍为 2026-01-19）
TRANSFER B C 80

# 源群 A 已解散，再用药 -> 报错（R4）
MED A 阿莫西林 2026-01-12

# 混群后休药期内出栏 -> 按最长剩余期拦截
SLAUGHTER C 2026-01-15 50        # 剩 4 天，拦截

# 到期日当天出栏 -> 放行
SLAUGHTER C 2026-01-19 50

# ============ 检疫拦截 ============
QUAR C FAIL
SLAUGHTER C 2026-01-20 10        # 检疫不合格，拦截
QUAR C PASS
SLAUGHTER C 2026-01-20 10        # 复检合格，放行

# ============ 非法引用 ============
MED ZZ 阿莫西林 2026-01-01       # 群不存在
MED C 不存在药 2026-01-01        # 兽药未定义
SLAUGHTER ZZ 2026-01-01 1        # 群不存在
SLAUGHTER C 2026-01-21 99999     # 数量不足
